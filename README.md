# 本草研习 · 执业中药师学习平台

React 19、TypeScript、Vite 与 Ant Design 5 构建的中文响应式网站。

## 开发

```sh
npm install
npm run dev
npm run build
npm test
```

## 按个人教材组织

网站默认进入“教材学习”。`data/` 下 58 份 Word 讲义按原始文件编号建立目录：中药一 6 份（前言及五个模块）、中药二 28 份、综合 14 份、法规 10 份。中药二第二十六、二十七章保留原讲义合并安排。四科 2025 第九版考试大纲提供 PDF 查看入口。

讲义约 86 万字，按原有授课标题分成 313 个阅读分段（包含章节开篇）。正文按章加载，保留文本、表格、原有例题和答案以及 1440 份去重插图。抽取脚本逐份验证去除空白后的正文文字与 Word XML 相同。网页不仿造 Word 页码；图片、表格及公式排版需要以原文件为最终依据。

现有 100 条知识笔记、218 道交互题保持 ID 和来源。88 条专题笔记归入教材对应章节；12 条历年复盘保留在“跨章复盘”分类。用户导入笔记能匹配章节时自动归档，其他资料标为补充资料。原有收藏、错题及学习进度继续有效。

每章集中提供讲义正文、关联补充笔记、章节交互练习、同科视频及考试大纲。讲义例题保留在正文，不自动推断或拆解成可判分题目。尚无交互题的章节明确显示空状态。全文检索可查药名、概念和讲义正文关键词。

阅读分段的已学状态及上次阅读位置保存在 `bencao-textbooks-v1`，随学习计划的完整备份一起导出；恢复兼容旧备份。视频课程、历年资料入口及原有判分功能继续保留。视频课堂只保留用户夸克课程，不认定与新讲义逐讲对应。

## 更新教材

原文件保留在 `data/`，不提交进 Git；生成的 `src/textbookCatalog.json` 与 `public/textbooks/` 用于静态部署。运行以下脚本重新提取（需要 Python 3，当前环境使用 Codex 打包的 Python）：

```sh
python scripts/build-textbooks.py
npm test
npm run build
```

脚本读取 OOXML，不修改原文件。四科讲义目录固定对应 `zy1`、`zy2`、`zh`、`fg`；讲义按文件名前的数字排序，阅读章节 ID 使用科目和文件编号。更新文件时应保留编号；授课分段 ID 随正文块位置生成，修改原讲义结构可能使旧分段进度无法对应。

原有公开来源、药材详表与历史题目仍保留独立出处。讲义表述沿用所提供版本，历史法规题沿用当年背景，未将其改写为现行法规结论。本站用于个人考试学习。

## 导入自己的资料

在“导入资料”下载 JSON 模板。三个数组为 `sources`、`knowledge`、`questions`，可按需提供；所有新记录的 `id` 必须唯一。知识引用有效 `sourceId`，题目引用同科目 `knowledgeId` 和有效 `sourceId`。科目编号：`zy1`、`zy2`、`zh`、`fg`。答案为从 0 开始的选项索引，单选一个，多选至少两个。使用个人笔记或获授权的资料，注明版本、页码与出处。

Word 讲义已内置于“教材学习”，考试大纲 PDF 可从教材页面查看；交互题库暂未完整覆盖讲义全部章节。个人 PDF 导入与阅读功能已移除。

## 数据与部署

学习数据保存在当前浏览器 `localStorage`，没有账号与服务器数据库，不自动跨设备同步。PC 和手机均可访问网站；结构化学习记录可使用“学习计划”中的备份导出与恢复。清除浏览器数据会清除这些内容，请保留备份。

`npm run build` 生成 `dist/`，可部署到任何静态托管服务。Sites 托管设置位于 `.openai/hosting.json`。站点为默认私有访问。

## GitHub CI 与 Release

`.github/workflows/release.yml` 在推送任意 tag 时触发，使用 Node.js 24 执行 `npm ci`、`npm test` 和 `npm run build`。测试与构建成功后，将 `dist/` 内的文件打包为 `dist.zip`，上传至 Actions 产物，并创建对应 tag 的 GitHub Release、附上同名压缩包。解压后根目录即为 `index.html` 和静态资源，可直接用于静态部署。同一 tag 重跑时更新已有 Release 的 `dist.zip` 附件。

先提交并推送需要发布的代码（包含 workflow），再推送版本 tag，例如：

```sh
git tag v1.0.0
git push origin v1.0.0
```

流程使用 GitHub 自动提供的 `GITHUB_TOKEN`，无需配置额外 Secret；仓库需启用 Actions，并允许 workflow 使用 `contents: write` 权限创建 Release。

## 验证

领域测试检查四科教材目录、完整分段覆盖、插图和大纲资产、章节归档与原有 ID 保留，以及多选判分、错题最新状态、内置资料完整性以及资料导入对重复 ID、非法 URL、无效答案和跨科目关联的拒绝。


## 夸克课程本地验证

B 站课程及生成目录已移除。视频课堂接入本机 OpenList 中转的中药一 2025 基础学习目录（当前 79 节）。支持站内播放、搜索、课程切换、进度跳转与浏览器内观看位置保存。

运行 `scripts/start-quark-local.ps1` 启动本机服务，打开 `http://127.0.0.1:5173` 的“视频课堂”。也可在已启动 OpenList 时运行 `npm run video:gateway` 与 `npm run dev`。

只读 WebDAV 地址为 `http://127.0.0.1:5244/dav/`，账号仅可读取课程目录。账号文件、OpenList 数据库和夸克会话保存在用户本机的 `%LOCALAPPDATA%/red-book-services/openlist`，未进入源码和网站构建。网站中转只接受本机请求，不能直接用于现有静态托管网站或其他设备；线上使用需要独立部署中转服务。网盘会话过期后需在本机 OpenList 更新。

## 教材划线与笔记

在讲义正文中选中文字，点击“划线”或“写笔记”。支持跨段选取和黄、绿、蓝三种划线颜色。点击正文划线可以修改颜色、编辑笔记或删除标注；每章“我的笔记”和教材目录的“我的划线与笔记”入口可查看记录并跳回原文。图片区不做文字识别。

标注按章节、授课分段、段落和文字偏移保存，重复词不会被同时划线。正文变动导致原文无法匹配时保留引用与笔记，不自动把旧划线移到别的文字上。记录存储在当前浏览器 localStorage（bencao-annotations-v1）；“学习计划”的完整备份包含标注，恢复兼容不含标注的旧备份。不会自动跨设备同步。


补充知识库的独立入口和页面已移除。教材章节中的关联笔记、收藏及题目关联仍由原有数据支持。

资料书架的导航、独立页面与概览跳转已移除。知识和题目中的原始来源引用继续用于出处标注。
