# 本草研习 · 执业中药师学习平台

React 19、TypeScript、Vite 与 Ant Design 5 构建的中文响应式网站。

## 开发

```sh
npm install
npm run dev
npm run build
npm test
```

## 已实现

- 电脑侧栏与手机抽屉导航，响应式知识卡和答题页面。
- 四科学习地图、知识搜索与章节筛选、知识详情、来源链接。8 味药材另有性味归经、药用部位、功效证候对应表、配伍、炮制差异与使用注意。
- 润德红宝书四科原书资料位，个人 PDF 导入、PDF.js 渲染、翻页、缩放、内置目录跳转、页码书签及内嵌文字提取。原书储存在 IndexedDB，不上传服务器。
- 章节练习、单选和多选判分、答案解析、关联知识。
- 最近一次作答状态驱动的错题本、重新练习、收藏、已学标记。
- 每日题数目标、打卡、考试目标日期、学习统计。
- 结构化 JSON 笔记和题目导入、格式与引用校验、完整备份导出及恢复。

## 内容范围

当前包含 88 条知识、184 道原创练习和 100 个资料入口。在原有资料基础上增加 64 味药材，按 16 个药类组织来源、功效、证候与辨析笔记，每味配 2 道原创基础练习。新增内容来自河南中医药大学公开药材馆，人工整理记录在 `research/herb-study-notes.json`，来源索引在 `research/herb-source-evidence.json`。8 味药材另有性味归经、配伍及炮制详表。科目依照 2026 年官方考试通知组织，考务入口优先展示江苏与苏州官方资料；本站并非完整考试教材。现有题目为原创巩固练习，**不是历年真题或红宝书原题**。润德原始题库与机构整理历年题仅提供可核对的原站入口，未导入本站。

用户备考 2026 年，接受 2025 版润德红宝书，尚未拥有原书。已检索两年版本及润德官网、出版社公开信息，但未取得可核验的完整 PDF 或完整目录。高教社的润德题库样章为 2020 年版，不作为 2025 原书接入。本站 **不含红宝书原文**，公开药材分类不是红宝书原目录，也不虚构页码。原书阅读功能必须添加实际 PDF 后才能阅读。逐章提取与红宝书页码对应仍未完成。高校旧资料的基原范围与药典条目不机械照搬；新增笔记保留基础事实，并提示按现行考试教材核对。

来源、知识和题目集中在 `src/data.ts`。每条知识、题目均关联来源。资料包括官方考试政策、现行法规与药监部门等公开科普，不复制整套商业教材。公开科普不是逐条核定的考试大纲，完整覆盖与教材校对仍需后续补充。

## 导入自己的资料

在“导入资料”下载 JSON 模板。三个数组为 `sources`、`knowledge`、`questions`，可按需提供；所有新记录的 `id` 必须唯一。知识引用有效 `sourceId`，题目引用同科目 `knowledgeId` 和有效 `sourceId`。科目编号：`zy1`、`zy2`、`zh`、`fg`。答案为从 0 开始的选项索引，单选一个，多选至少两个。使用个人笔记或获授权的资料，注明版本、页码与出处。

PDF 在“原书阅读”添加，支持阅读与本页内嵌文本提取，不自动将其变成结构化知识。扫描件不自动 OCR，Word 暂不支持。后台资料审核、完整教材章节与授权历年题库仍需后续补充。

## 数据与部署

学习数据保存在当前浏览器 `localStorage`，个人 PDF 与阅读位置、书签储存在 IndexedDB，没有账号与服务器数据库，不自动跨设备同步。PC 和手机均可访问网站；结构化学习记录可使用“学习计划”中的备份导出与恢复，PDF 需保留原文件并在另一设备单独添加。清除浏览器数据会清除这些内容，请保留备份。

`npm run build` 生成 `dist/`，可部署到任何静态托管服务。Sites 托管设置位于 `.openai/hosting.json`。站点为默认私有访问。

## 验证

领域测试检查多选判分、错题最新状态、内置资料完整性以及资料导入对重复 ID、非法 URL、无效答案和跨科目关联的拒绝。
